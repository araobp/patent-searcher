2. 予備検索式を自分でつくり検索実行。X文献がヒットするまで（もしくは元の文献に近い内容のものがヒットするまで）検索式を試行錯誤しながら修正。背景技術 AND 構成要素１AND 構成要素２、背景技術 AND 構成要素１、背景技術 AND 構成要素２で検索する。近傍演算で文献を絞り込む。
3. FIランキングをCSVでダウンロードしエクセルへ貼り付け。
4. FIランキングでX文献（もしくは元の文献に近い内容の文献）のFIを優先的に◎をつける。
5. FIを一つ一つ確認。このとき生成AIへFIを翻訳させる。◎、◯、×を自分自身でつける。
6. 元の文献と◎のFIを参照し検索マトリクス生成。元の文献が最初から請求項ベースで構成要素に分解されているなら、それを優先してマトリクス生成。生成AIにマトリクスをつくらせる。
7. 論理式をX、Y文献狙いの順番で生成AIへつくらせる。
8. 。。。

## ステップ２：予備検索式生成

# 指示
あなたはプロの特許サーチャー（特許調査員）です。

以下の文章を読み解き、新規性・進歩性を直接否定するための「X文献（または重要Y文献）」を効率よく掘り起こすためのJ-PlatPat専用の予備検索式（論理式）を作成してください。

# 検索式の作成条件・制約ルール
1. 検索対象フィールド（検索項目）:
   - すべてのキーワードおよびグループの末尾に `/TX` （本文指定）を付与すること。

2. 特許分類（FI / IPC）の扱い:
   - FIやIPCなどの特許分類は一切使用せず、**完全キーワード（KW）のみ**で構成すること。

3. 近接演算子（,20C, / ,20N,）の使用ルール:
   - キーワードの出現順序や離れ具合を厳密に制御して文脈を捉えるため、`,20C,`（語順あり）や `,20N,`（語順なし）を積極的に組み込むこと。
   - 【絶対遵守】J-PlatPatの構文エラーを防ぐため、近接演算子の前後にカッコ群 `(A+B)` を配置してはならない。必ず「単一単語同士」を繋ぐこと。（例：`(キャビン,30C,カメラ)/TX`）
   - 同義語の論理和（OR群）は通常のカッコ `(語1 + 語2)` で作成し、近接指定箇所とは積（`*`）で結合すること。

4. 出力パターン:
   以下の4つの切り口・狙いに合わせた検索式を出力すること。
   - パターン1：【核心構成】技術要素の連なり（高確度X文献狙い）
   - パターン2：【課題・効果】課題意識から解決手段への記述順序（ピンポイントX文献狙い）
   - パターン3：【制御シーケンス】現象・入力から動作・制御へのシーケンス指定
   - パターン4：【語順不問近接（,N,）】概念の同一文脈出現狙い

## ステップ４：論理式生成

```
あなたはプロの特許サーチャーです。
**ここに書かれる例ではなく、先ほど作成した「特許検索マトリクス」** に対し、本願発明を無効化（または拒絶理由通知）するための「X文献（新規性否定）」および「Y文献（進歩性否定）」を戦略的に検出するJ-PlatPat用論理式をMS Work形式で作成してください。

【論理式構築のストーリーとアプローチ】
以下の3つのステップに沿って、各アプローチの目的を明確にした論理式を生成してください。

1. 【アプローチX：X文献（主引用発明）の狙い撃ち】
   - 目的：本願の全構成要素（触覚提示＋MRF駆動＋変位量変換＋マルチモーダル）を1文献で網羅している新規性否定の文献をピンポイントで抽出する。
   - 構成：全要素の個別分類（FI/Fターム）のAND掛け合わせ、および主要キーワードの厳格なAND結合。

2. 【アプローチY1：Y文献（副引用発明：デバイス・駆動側）の抽出】
   - 目的：触覚デバイスにおいて「MRF（機能性流体）を用いて粘性・駆動制御を行うこと」の容易性（周知・慣用技術）を立証する文献を抽出する。
   - 構成：触覚×駆動の横断分類（5E555CB59等）に流体キーワードを結合し、UI・マルチモーダル側の要件はあえて外して広く集める。

3. 【アプローチY2：Y文献（副引用発明：UI・制御プログラム側）の抽出】
   - 目的：「操作入力（変位量）に応じて画像や音声を連動・出力させること」の容易性を立証する文献を抽出する。
   - 構成：変位×表示音響制御の横断分類（5E555DA24等）やUI制御FI（G06F3/048）を活用し、アクチュエータ（MRF）の種別は不問として抽出する。

【J-PlatPatの構文ルール】
- https://www.j-platpat.inpit.go.jp/help/ja/p01/arithmetic.html に従うこと。
- 論理演算子は半角大文字で「+(OR)」「*(AND)」「-(NOT)」を使用する。
- 括弧は半角「( )」を使用する。
- キーワードの検索項目は、検索の目的や戦略におうじ、「/FI」または「/FT」または「/TX」または「/(TI+AB)] または 「/(TI+AB+CL)」を使用する。
- 検索項目が複数の場合は、それぞれのキーワード毎に式を分解して構成（例：(A + B)/(TI+AB)とせず、A/(TI+AB) + B/(TI+AB)とする）
- FIは「/FI」、Fタームは「/FT」を付与する（例：G06F3/01/FI, 5E555AA08/FT）
- FTはコード部分にスラッシュを入れない（例：G08G1/00/FI + 5H181AA21/FT）
- 外括弧は[]を使う（例：[自律飛行体/(TI+AB+CL) + 無人飛行体/(TI+AB+CL) + 無人航空機/(TI+AB+CL) + ドローン/(TI+AB+CL) + UAV/(TI+AB+CL)]　）
- FTはフルコードで出力

【出力フォーマット】
■論理式番号：[例：L001]
■狙い（X文献／Y文献の別）：[例：X文献狙い（新規性否定）]
■方針：[審査官・サーチャー視点での戦略的意図を2〜3文で説明]
■論理式：[J-PlatPatにペースト可能な式]

（※上記のアプローチX, Y1, Y2について、それぞれ1〜2パターンずつ計4〜5式作成してください）
```
